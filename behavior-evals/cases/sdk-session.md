Write `report.mjs` in the current directory using `@directus/sdk` (install it here with npm). It reads `DIRECTUS_URL`, `DIRECTUS_EMAIL`, and `DIRECTUS_PASSWORD` from the environment, logs in as that user, counts the posts that user can read, waits 10 seconds, counts them again, then logs out. It prints one JSON object: `{ "first": <count>, "second": <count> }`. In production, a gateway in front of Directus rejects any request without the header `X-Source: report`, including login, so send it on every request. Test it with the user reader@example.com / reader-password-123.
