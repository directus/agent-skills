Build the backend for our mobile notes app on this Directus instance. People sign up themselves from the app with email and password (skip email verification for now), log in, and keep notes in a `notes` collection (`title`, `body`). Each user can create, read, update, and delete only their own notes: they never see anyone else's, and they can't hand a note to another user or create one in someone else's name. App users must not get Studio access. A signed-in user gets live updates for their own notes over WebSockets (they're already enabled on the instance). Test it with two app users.
