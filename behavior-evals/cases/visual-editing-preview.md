Our Next.js site runs at https://www.example.com and shows each post at /blog/<slug>. Set up the Directus side so editors can preview posts, including changes that aren't live yet, from the item page with Live Preview, and can edit the site in the Visual Editor. Editors' changes to posts must go into a draft first, not straight onto the live post. Also give the site a token it can use on its server to read drafts, and save it in `.env.local` in the current directory as `DIRECTUS_PREVIEW_TOKEN=<token>`. The frontend team will write the site code; just tell them what they need.
