# 10.x minors: 10.0 to 10.13.4

Read only the sections after your current version. Next: `11.0.md`.

## 10.2.0: `/server/info` trimmed

No Directus version, Node version and uptime, or OS info. Who: monitoring or scripts reading `directus.version`,
`node`, or `os`. Detect `rg -n "server/info" -g '!node_modules'`. Fix: on 10.2.0 to 10.8.2, `GET /server/health` with
an admin token returns the version as `releaseId`; from 10.8.3, authenticated `/server/info` returns `data.version`.

## 10.4.0: Redis env consolidated, Memcached dropped; extension errors

- `CACHE_REDIS*`, `RATE_LIMITER_REDIS*`, `SYNCHRONIZATION_REDIS*`, `MESSENGER_REDIS*` → one set of `REDIS*` vars.
  Memcached no longer supported for cache or rate limiting. Detect
  `rg -n "(CACHE|RATE_LIMITER|SYNCHRONIZATION|MESSENGER)_REDIS|memcache" .env* docker-compose* *.yaml *.yml`. Fix:

  ```ini
  REDIS_HOST="127.0.0.1"
  REDIS_PORT="6379"
  CACHE_STORE="redis"
  RATE_LIMITER_STORE="redis"
  SYNCHRONIZATION_STORE="redis"
  MESSENGER_STORE="redis"
  ```

  Replace any `*_STORE="memcache"` with `redis` or `memory`.

- `exceptions` removed from the extension context. Detect
  `rg -n "exceptions\b|ForbiddenException|InvalidPayloadException|ServiceUnavailableException" extensions/ src/`. Fix:
  `import { createError } from '@directus/errors'; const ForbiddenError = createError('MY_EXTENSION_FORBIDDEN', 'Not allowed', 403);`

## 10.6.x: Run Script sandbox, SDK `refresh`, malformed conditions

- 10.6.0: Run Script operations (`isolated-vm`) can't `require` npm modules (axios, node-fetch, ...). Detect
  `SELECT id, options FROM directus_operations WHERE type = 'exec';` and look for `require(`. Fix: Webhook / Request
  URL operation for HTTP, or a custom operation extension.
- 10.6.2: SDK `refresh('json', refresh_token)` (mode first); `asSearch` → `withSearch`. Detect
  `rg -n "refresh\(\s*['\"]?[a-zA-Z_]+['\"]?\s*,\s*['\"](cookie|json)['\"]|asSearch" src/`. 11.9.0 changes `refresh`
  again.
- 10.6.3: only instances that edited field conditions on 10.6.2. Re-save them
  (https://github.com/directus/directus/issues/19757#issuecomment-1734162756).

## 10.7.0 to 10.9.0: extensions endpoint, GraphQL versions, SDK imports

- 10.7.0: `GET /extensions/:type` removed; `GET /extensions` returns all with type and status. Detect
  `rg -n "/extensions/(interfaces|displays|layouts|modules|panels|endpoints|hooks|operations|bundles)" src/`.
- 10.8.3: GraphQL `version` argument on `<collection>_by_id` and `<collection>` → `<collection>_by_version(id, version)`
  and the system `versions` query. SDK `ExtensionItem` → `DirectusExtension`. Detect
  `rg -n "_by_id\([^)]*version:|\(version:|ExtensionItem" -g '*.{graphql,gql,ts,js,vue,tsx}'`.
- 10.9.0: SDK scoped imports (`@directus/sdk/rest`) gone, import from `@directus/sdk` (detect `rg -n "@directus/sdk/" src/`).
  JS config files can't run async code (`rg -n "async|await" config.js config.cjs config.mjs`). `exif-reader` v2
  renamed Exif tags for new uploads: check a custom `FILE_METADATA_ALLOW_LIST` and code reading
  `directus_files.metadata`. Regenerate tracked schema snapshots (field order changed).

## 10.10.0: extensions and auth

| Change                                                                 | Detect                                                                            | Fix                                                                                                             |
| ---------------------------------------------------------------------- | --------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Typed extension folders (`extensions/interfaces/x`) are ignored        | `ls extensions/` (sweep below)                                                    | Move each up one level (`extensions/<name>/`), add `directus:extension` (`type`, `path`, `source`, `host`)      |
| Migrations and email templates are no longer extension types           | `extensions/migrations/`, `extensions/templates/` exist                           | Move to `./migrations` / `./templates`, or set `MIGRATIONS_PATH` / `EMAIL_TEMPLATES_PATH`                       |
| Studio uses session cookie auth; SSO providers default to session mode | External apps relying on SSO's refresh token cookie; `rg -n "AUTH_.*_MODE" .env*` | `AUTH_<PROVIDER>_MODE=cookie` for the old behavior (doesn't work with the Studio). Configure `SESSION_COOKIE_*` |
| App extensions can't read the token from `axios`                       | `rg -n "Authorization" extensions/`, `rg -n "access_token=" extensions/`          | Drop the token logic; the session cookie is sent automatically                                                  |
| `AuthenticationService.login(email, password, otp)` → options object   | `rg -n "AuthenticationService" extensions/`                                       | `login('email', 'password', { otp: 'otp-code', session: true })`                                                |
| SSO redirects need an allow list                                       | `?redirect=` to an external domain after SSO                                      | `AUTH_<PROVIDER>_REDIRECT_ALLOW_LIST`                                                                           |
| Send Email operation no longer waits for delivery                      | Flows reading its result                                                          | Custom operation using `MailService`                                                                            |
| Versioned item reads resolve O2M changes                               | Code reading raw version deltas                                                   | `?versionRaw=true`                                                                                              |
| Extension management endpoints keyed by primary key, not npm name      | `rg -n "updateExtension" src/`                                                    | Use the extension `id`                                                                                          |

## 10.10.5 to 10.13.2

- 10.10.5: webhooks deprecated and auto-migrated to flows (table dropped in 11.14.1).
- 10.11.0: `search` on a collection with no searchable fields returns nothing (was everything). Detect
  `rg -n "search=|search:" src/`. SDK realtime WebSocket client is created with a `string` URL.
- 10.12.2: nested relational writes into `directus_collections`, `directus_fields`, `directus_relations`,
  `directus_sessions`, `directus_extensions` are rejected. Use their own endpoints.
- 10.13.0: admin users count toward the app access limit; services call their corresponding services internally (hooks
  may fire where they didn't before).
- 10.13.2: `directus_files.created_on` added; `uploaded_on` updates on every upload or replace. Use `created_on` for
  "created".

## Grep sweep

```bash
rg -n "@directus/sdk/|asSearch|ExtensionItem|exceptions\b|_REDIS_|memcache|AuthenticationService|/extensions/(interfaces|endpoints|hooks)" \
  -g '!node_modules' -g '!dist'
ls extensions/ | rg "^(interfaces|displays|layouts|modules|panels|endpoints|hooks|operations|bundles|migrations|templates)$"
```
