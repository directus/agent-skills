# v9 to 10.0.0

The hop from any 9.x to 10.0.0. Next: `10.x-minors.md`.

**House rule:** on v9, upgrade to 9.26.0 first and boot it once, then go to 10.x.

## 9.25.0: ESM and Node 18

- **API moved from CommonJS to ESM.** API extensions built with the extensions SDK should still load, but test them.
  Detect: ESM/CJS import errors in the logs when extensions load. Fix: rename extension output to `.cjs`, or bundle as
  native ESM.
- **`directus` requires Node `>=18.0.0`** (was `>=12.20.0`). Detect: `node --version`, `engines` in `package.json`,
  `FROM node:` in Dockerfiles. Fix: Node 18+; Node 22 is needed from 11.4.0, so jump straight to 22 if going further.

## 10.0.0: license change only

One commit over 9.26.0: `directus`, `@directus/api`, `@directus/app` and several packages relicensed from GPL to BSL
1.1. No code or schema changes. Check the license fits your organization (12.0 changes it again, see `12.0.md`).
