# 12.x minors: 12.0 to 12.6.0

Breaking changes between 12.0.0 and 12.6.0. Read only the sections after your current version. Each `.0` minor below
breaks; patches don't, except that 12.4.0 is broken (use 12.4.1). The SDK took a new major with every 12.x minor up
to 12.5 (12.6 is a minor): match it to the server (`sdk-and-extensions.md`).

## 12.1.0

- **`/utils/hash/generate` and `/utils/hash/verify` removed** (API, SDK, specs). Detect
  `rg -n "utils/hash|generateHash|verifyHash" -g '!node_modules'`. Fix: a custom endpoint extension using `argon2`.
- **Sensitive GraphQL system mutations limited to one per request** (`GRAPHQL_SINGLE_USE_MUTATIONS`). Split batches.
- GraphQL over WebSockets gets the HTTP restrictions; validation hints hidden when introspection is off.
- **`CORS_ORIGIN` enforced for WebSockets.** Detect `rg -n "realtime\(|WEBSOCKETS_ENABLED" -g '!node_modules'`; make
  `CORS_ORIGIN` list every client origin.
- Upload paths can't target extension or temp storage directories.
- **Docker image has no `npm` or `npx`;** a `-dhi` distroless variant (no shell) is published. Detect
  `rg -n "npx|npm (i|install)" Dockerfile* docker-compose* entrypoint* scripts/`. Fix: install extensions in a
  multi-stage build; run the CLI as `node /directus/cli.js <command>`.
- New: `PROJECT_OWNER_ENABLED` (default `true`).

## 12.2.0

- **WYSIWYG (`input-rich-text-html`) moved from TinyMCE to Tiptap.** Same interface id, options, HTML storage.
  Unsupported markup (`<div>` wrappers, HTML comments, `<script>`, `<style>`, unsupported inline styles) is removed
  when an editor saves; fields containing it open read-only with a diff dialog. `tinymceOverrides` has no effect; the
  global `tinymce` is gone. Detect `rg -n "tinymce|tinymceOverrides" extensions/ snapshot*`, then
  `SELECT collection, field FROM directus_fields WHERE interface = 'input-rich-text-html';` and check stored HTML for
  `<div` or `style=`.
- **New App Access policies read only a limited set of `directus_settings` fields.** Existing policies are untouched and
  still expose all settings, including `ai_openai_api_key` and other provider keys: audit and scope them. Non-admin
  readers of other settings fields need them added to the policy.
- **`IMPORT_MAX_FILE_SIZE` defaults to `50mb`** for import endpoints and `/schema/diff`, `/schema/apply` uploads (413).
- **`ASSETS_TRANSFORM_IMAGE_MAX_OUTPUT_DIMENSION`** (`3000`; `6000` from 12.3), checked at every transform step;
  violations fail `ILLEGAL_ASSET_TRANSFORMATION`.
- **Valueless boolean query flags mean true.** `POST /utils/import/:collection?background` runs in the background;
  `POST /schema/apply?force` bypasses the apply's **hash** check (target schema changed since the diff).
  `POST /schema/diff?force=false` is respected; `force` there bypasses the version and vendor check. The docs say apply
  `force` bypasses version and vendor; the v12.5.1 source says hash. Detect
  `rg -n "\?force\b|&force\b|\?background\b|&background\b" -g '!node_modules'` and pass explicit values. What each
  schema path checks: `directus-environment-sync` ("Schema snapshot and apply").
- **SDK `schemaDiff(snapshot, true)` → `schemaDiff(snapshot, { force: true })`.** Detect
  `rg -n "schemaDiff\([^)]*,\s*(true|false)" -g '!node_modules'`.
- `DeploymentProjectsService.readByExternalId(deploymentId, externalId)` takes the deployment id first.
- New: `LICENSE_KEY_MANAGEMENT_ENABLED` (default `true`).

## 12.3.0

- **Update Items and Delete Items flow operations no longer target every item** when key and query are empty; they
  return `null`. Key and query both set throws; Update Items with a batch payload plus key or query throws. Fix: query
  `{"limit": -1}` for "all items". Detect
  `SELECT id, flow, options FROM directus_operations WHERE type IN ('item-update', 'item-delete');`
- **Storage driver `exists()` throws on connection or auth failures** instead of returning `false`. Extensions must
  catch (`rg -n "\.exists\(" extensions/`). S3: grant `s3:ListBucket` so a missing object reads as missing.
- `ASSETS_TRANSFORM_IMAGE_MAX_OUTPUT_DIMENSION` default `6000`; set `3000` to keep the 12.2 limit.
- **Docker image boots with `CMD ["node", "docker-entrypoint.cjs"]`** (bootstrap, then `pm2-runtime`, which is not on
  `PATH`). Detect `rg -n "pm2-runtime" Dockerfile* docker-compose*`; hand off to `docker-entrypoint.cjs`.
- SDK 25 corrects types for `directus_files`, `directus_collections`, `directus_deployments`, `directus_settings`,
  `directus_users`. Expect TS errors.

## 12.4.0 (use 12.4.1)

12.4.0 breaks `GET /folders` and the File Library for non-admins (500); 12.4.1 fixes it. The rest applies to both.

- **Inactive collections reject reads and writes:** `COLLECTION_INACTIVE` (403) for users with permission, `FORBIDDEN`
  for others. Covers REST, GraphQL, WebSockets, flows, nested relational writes, filters or sorts through relations.
  Wildcards drop O2M and M2A aliases pointing at inactive collections. License resolution makes collections inactive.
  Detect `GET /collections`, look for `meta.status: "inactive"`. Fix: reactivate in collection settings, or license.
- **`updateByQuery` / `deleteByQuery` enforce read permissions:** read on the primary key needed; only readable items
  touched; `filter` and `sort` fields must be readable; nested O2M saves need read on the child. Applies to
  `PATCH`/`DELETE` with a `query`, GraphQL equivalents, non-admin Update/Delete Items operations. Fix: matching read
  permissions on update/delete policies.
- **Flow folders share `directus_folders`** with a `type` (`files` or `flows`); admin `GET /folders` returns both. Fix
  `GET /folders?filter[type][_eq]=files`. Detect `rg -n "/folders|readFolders" -g '!node_modules'`.
- Map layout and interface need WebGL2 (MapLibre 6). Safari 14 and older lose maps.
- **`@directus/themes` peers on `@unhead/vue` 3:** `createHead` from `@unhead/vue/client`; template params need
  `TemplateParamsPlugin`. Detect `rg -n "@unhead/vue|@directus/themes" package.json`.
- **Type corrections** in `@directus/types` 17 and `@directus/sdk` 26, mostly fields made nullable;
  `DirectusPolicy.ip_access` and `DirectusRelation.meta.one_allowed_collections` are `string[]`; `ToTuple` and
  `TupleToUnion` removed. Run `tsc --noEmit`. At runtime the SDK throws before sending when `readRelationByCollection`,
  `createField`, `deleteCollection`, `utilsExport`, `utilsImport`, `utilitySort`, `triggerFlow`, `readShareInfo` get
  empty params.
- New: Mailtrap transport (`EMAIL_TRANSPORT=mailtrap`, `EMAIL_MAILTRAP_TOKEN`, ...).

## 12.5.0

- **Stricter IP validation** for policy `ip_access` and `IMPORT_IP_DENY_LIST`. Allowed: single IPv4/IPv6, a same-family
  range `a-b` with no spaces, or CIDR with a numeric prefix. Invalid policy values are **not migrated**: every request
  from a user with that policy fails 500, including login. An invalid `IMPORT_IP_DENY_LIST` entry denies every outbound
  request that checks the list (file imports, Request URL operation, sandboxed extensions). Detect before upgrading:
  `SELECT id, name, ip_access FROM directus_policies WHERE ip_access IS NOT NULL;` and
  `rg -n "IMPORT_IP_DENY_LIST" .env* docker-compose*`; look for spaces, `+`, non-numeric prefixes. If the policy is
  your own admin's, fix it in the DB.
- **2FA enforcement uses effective policies:** Require 2FA on a parent role or assigned directly to a user applies;
  with an IP allow list, only from allowed IPs. Affects SSO logins and clients reading the `enforce_tfa` token claim.
- **`CACHE_SCHEMA_MAX_ITERATIONS` removed.** `CACHE_SCHEMA_SYNC_TIMEOUT` bounds the whole schema build, default
  `60000` ms (was `10000`). Detect `rg -n "CACHE_SCHEMA_MAX_ITERATIONS|CACHE_SCHEMA_SYNC_TIMEOUT" .env* docker-compose*`.
- **`GET /license`** drops `downgrade_reason`; read `invalid_reason` (also `verification`, `invalid_key`,
  `activation_limit`, `binding_mismatch`, `unavailable`) and `token_expires_at`.
- **`@directus/errors` 3.0** drops `LicenseManagedByEnvError`, `LicenseOfflineUnsupportedError`,
  `LicenseResolveIncompleteError`, `LicenseServiceUnavailableError`, `LicenseImmutableError` and their codes. License
  failures surface as `LICENSE_INVALID` (400, `failure` extension) or standard errors; binding mismatch and activation
  limit used to be `FORBIDDEN`. Detect `rg -n "License[A-Za-z]*Error|LICENSE_" extensions/ src/`.
- **File `storage` must be in `STORAGE_LOCATIONS`** (exact, case-sensitive) on create, upload, or update, else
  `INVALID_PAYLOAD`. TUS replacement only works for files in the first location. Detect
  `rg -n "storage:\s*['\"]" -g '!node_modules'` in import scripts and seeders.
- **Type corrections** in `@directus/sdk` 27 and `@directus/types` 18: notification `id` is `number`;
  `FieldMetaConditionOptionType` removed (condition `options` is `Record<string, any>`); several field, condition, and
  `ExtensionSchema` properties nullable or optional. Run `tsc --noEmit`. At runtime SDK `readActivity`,
  `readNotification`, `readRevision`, `readPermission`, `updatePermission`, `deletePermission`, `readItemPermissions`
  throw on `null`/`undefined` keys.
- Behavior: a failed license renewal keeps the current license and retries. GraphQL nullability of fields with defaults
  fixed (generated GraphQL client types may change). Creating a collection with neither `schema` nor `meta` returns 400
  instead of 403. Linked images (`<a>` wrapping `<img>`) supported in the WYSIWYG.
- 12.5.1: patch, no breaking changes. Docker images pin Node `22.23.4`.

## 12.6.0

- **Node.js 26 required.** `directus` and `create-directus-project` declare `node >=26`; Node 22 is unsupported. Docker
  images ship Node `26.12.1`. npm installs: upgrade Node before the package. Detect `node --version`, then
  `rg -n "node:2[0-5]|NODE_VERSION|\"node\":" Dockerfile* docker-compose* .nvmrc package.json .github/`. Rebuild
  API extensions with native modules on Node 26.
- **Node 26 images have no Corepack.** A build stage moved to `node:26-alpine` fails on `corepack enable`. Fix:
  `RUN npm install --global pnpm@<version>` (the 12.6.0 Dockerfile does this). Detect `rg -n "corepack" Dockerfile*`.
- **Telemetry and compliance reports go to `https://telemetry.directus.com`** (`TELEMETRY_URL`, `COMPLIANCE_URL`
  defaults; was `telemetry.directus.io`). With restricted egress, allow it before upgrading: failed reports log no
  error. Detect `rg -n "telemetry\.directus\.io|TELEMETRY_URL|COMPLIANCE_URL" .env* docker-compose* infra/ 2>/dev/null`.
- **OpenAPI schema `x-metadata` renamed `Metadata`** in `/server/specs/oas` and `@directus/specs` 16. List responses
  reference `#/components/schemas/Metadata` for `meta`. Detect `rg -n "x-metadata" -g '!node_modules'`; update `$ref`s
  and regenerate clients built from the spec.
- **AI allowed models:** unset (`null`) provider lists now mean "recommended defaults", which change with releases.
  Saved lists are kept, but deprecated ids are gone from the built-in lists (`gpt-4.1-nano`, `gpt-5.1-chat-latest`,
  `gpt-5.2-chat-latest`, `gemini-3-pro-preview`, `gemini-3.1-flash-lite-preview`) and may fail at the provider. Detect
  `SELECT ai_openai_allowed_models, ai_anthropic_allowed_models, ai_google_allowed_models FROM directus_settings;`.
  Fix: recheck **Settings → AI**, or set a field to `null` to follow the defaults.
- **`PUBLIC_POLICY_ID` removed from `@directus/constants`.** The Public policy row keeps its id. Detect
  `rg -n "PUBLIC_POLICY_ID" extensions/ src/`; inline the id or read the policy attached with `role = null`.
- **`/mcp` returns `405` (`Allow: POST`) for authenticated `GET` and `HEAD`.** MCP health checks must `POST`.
- Migration adds `directus_settings.default_exports_folder` (FK to `directus_folders`). Exports to the File Library
  without `file.folder` land there when set. App Access users can read it and `storage_default_folder`. `d6s` 12.4.0
  strips it from settings like `storage_default_folder`; older CLIs copy the source's folder id.
- `RETENTION_BATCH` is capped at the database's binding limit (Oracle `999`, MSSQL `2097`); a non-integer or value
  below 1 disables retention with an error log.
- New: `richtext` app extension type (Tiptap nodes, marks, toolbar buttons for the WYSIWYG, opted in per field), SDK
  `customEndpoint` sends `FormData` as multipart. Fixed: `directus init` before `.env` exists, bootstrap on MSSQL.

  -g '!node_modules' -g '!dist'
