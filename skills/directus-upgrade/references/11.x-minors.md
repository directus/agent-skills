# 11.x minors: 11.0 to 11.17.4

Breaking changes between 11.0.0 and the last 11.x (11.17.4). Read only the sections after your current version.
Next: `12.0.md`.

## 11.1.x and 11.2.2: SendGrid, comments, TUS

- 11.1.1: SendGrid transport removed. Detect `rg -n "EMAIL_TRANSPORT=.?sendgrid|EMAIL_SENDGRID" .env* docker-compose*`.
  Fix: SendGrid's SMTP relay with `EMAIL_TRANSPORT=smtp`.
- 11.1.2: comments move to `directus_comments` with **UUID** keys (old activity-based endpoints still work). Detect
  `rg -n "action.*comment|ActivityService|createComment|comment.*activity" -g '!node_modules'`. Fix: `/comments` and
  `CommentsService`, string ids, SDK updated alongside the server.
- 11.2.2: `TUS_CHUNK_SIZE` defaults to `8mb`; `chunkSize` enforced even with TUS off. Check custom upload clients.

## 11.4.0 to 11.7.0: Node 22, flows, GraphQL ids, MySQL 5.7

- 11.4.0: `directus` and `@directus/*` require Node 22 (`engines.node: ">=22"`). Only in the release notes, not the
  docs breaking-changes page. Detect `node --version`;
  `rg -n "FROM node:|node-version|nodejs" Dockerfile* .github/ .nvmrc .node-version`.
- 11.5.0: a failed condition operation throws `FailedValidationError`. Update flows branching on the old error.
- 11.6.0: GraphQL primary keys are `ID`. Detect `rg -n '\$[a-zA-Z_]*[iI]d:\s*String' -g '*.{graphql,gql,ts,js,vue}'`;
  change to `ID` / `ID!`, regenerate client types. `items.create` action hooks get the final payload (after filter
  hooks and presets).
- 11.7.0: MySQL 5.7 dropped. Upgrade the database first.

## 11.9.0: SDK auth signatures, manual flows need auth

```bash
rg -n "\.login\(\s*[^{]" -g '!node_modules'           # positional login(email, password)
rg -n "refresh\(\s*['\"](json|cookie)" -g '!node_modules'
rg -n "logout\(\s*['\"]" -g '!node_modules'
```

Fix: `login({ email, password })` (LDAP: `login({ identifier, password })`), `refresh({ mode: 'json', refresh_token })`,
`logout({ mode, refresh_token })`. Manual-trigger flows require an authenticated user; public callers use a webhook
trigger. Extensions SDK on Rollup v4.

## 11.10.x: snapshots, `NODE_ENV`, typed services

- Snapshots exclude database-only tables (not in `directus_collections`). Applying an 11.10+ snapshot to a pre-11.10
  instance **drops** those tables. Upgrade source and target together.
- API extensions see the real `NODE_ENV` instead of hardcoded `production`. Extensions SDK on latest Rollup and Vite,
  Node `>=20.19.0`.
- 11.10.1: extension context services are typed. Expect TS errors (`string | undefined` collection names, nullable keys
  in `readOne`). Detect `tsc --noEmit` per extension. Quick unblock: `services as any`.

## 11.11.0 and 11.12.0: content versioning reads

- Relational versioned data needs explicit field expansion; invalid data errors on query; query params apply to the
  versioned data. Querying a version runs in a transaction (deadlocks possible; SQLite blocks other requests). New
  relational records inside a version return `id: null` until promoted.
- 11.12.0: `user_created`, `user_updated`, `date_created`, `date_updated` reflect real edits, not promotion. A
  non-existent version key returns Forbidden instead of the main item.
- Detect `rg -n "version[=:]" -g '!node_modules'` and review each versioned read.

## 11.13.0 to 11.15.0

- 11.13.0: `<scope>.delete` filter hooks run **before** permission checks, and returned keys replace the original keys;
  add your own checks (`rg -n "\.delete['\"]" extensions/`). `presentation` and `group` removed from `RELATIONAL_TYPES`.
  System collection fields can only be changed to add indexes. API extensions built with Node export conditions.
- 11.14.0: `navbarOpen`, `sidebarOpen`, `fullScreen` removed from `appStore`.
- 11.14.1: **webhooks removed** (API, SDK, types, Studio; `directus_webhooks` dropped by `20251224A-remove-webhooks`;
  not on the docs breaking-changes page). Auto-migrated to flows in 10.10.5. `GET /assets/:id` respects
  `directus_files` field permissions. SSO callback and redirect validation include the port; check `PUBLIC_URL` and
  redirect allow lists. `AI_ENABLED` turns off the AI assistant.
- 11.15.0: disabled interfaces are no longer interactive (including opening drawers on read-only relational fields).

## 11.16.0 and 11.17.0

- 11.16.0: versioned items get a global `draft` version; existing versions keyed `draft` get the display name "Draft".
  Visual editing field and version checks need `@directus/visual-editing` **v2.0.0+**
  (`rg -n "@directus/visual-editing" package.json`). `UsersService.requestPasswordReset` throws Forbidden for external
  auth users.
- 11.17.0: imports time out after 1 hour, max 20 concurrent (`IMPORT_TIMEOUT`, `IMPORT_MAX_CONCURRENCY`).
  `@directus/types/collab` exports moved to `@directus/types`. Studio shrunk to 90%, rem on a 16px root: app extensions
  with hardcoded px or a 14px root assumption may look off.

```bash
  -g '!node_modules' -g '!dist'

```
